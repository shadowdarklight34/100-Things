# 🌸 100 Things About You ✨

## ✨ Features

- 🌸 **Type Garden Intro**: Interactive procedural botanical typography where typing blooms vines, leaves, and roses in real-time.
- 🌠 **Star Rain & Celestial Canvas**: Multi-layered twinkling night sky with cascading shooting stars and meteor shower animations.
- 🌟 **Jar of 100 Lucky Stars**: Folded lucky origami stars in a glass jar that unfold secret reasons and trigger shooting star showers.
- 🎨 **4 Aesthetic Themes**: Default **Sakura** 🌸, Midnight 🌙, Lavender 💜, and Aurora 🌌.
- 🎵 **Soundtrack & Music Picker**:
  - Vinyl player with dancing audio visualizer bars
  - Preset soothing lofi and piano tracks
  - Support for custom direct audio URLs
  - Direct local audio file upload from mobile or desktop
- 💌 **Secret Note / Crush Admiration**: Sweet heartfelt note written respectfully for your crush.
- 📱 **Mobile First & PWA Ready**: Touch swipe gestures (left/right), haptic feedback, safe-area padding for notches, and responsive controls.
- 📸 **Instagram Story Card Export**: High-resolution 9:16 export with golden typography ready to share.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/shadowdarklight34/100-Things.git
cd 100-Things

# Install dependencies
npm install

# Run locally
npm run dev

# Build for production
npm run build
```
