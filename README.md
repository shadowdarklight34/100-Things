# ✨ 100 THINGS ABOUT YOU

An atmospheric, deeply aesthetic web application recreating the viral Python/Pygame tribute. Built with modern, professional web technologies (**React 19, TypeScript, Vite, Tailwind CSS**) optimized for both **mobile devices** and **desktop screens**.

---

## 🌟 Features

- **100 Exact Poetic Statements**: All 100 statements recovered, verified, and styled with golden glowing italics (`*highlighted words*`).
- **Cinematic Visuals**:
  - Deep obsidian & stardust midnight background with warm ambient radial glow.
  - Interactive canvas particle system with floating golden stardust and embers.
  - Multi-layered horizontal drifting ambient quotes recreating the Pygame visual atmosphere.
  - Luminous golden serif typography (`Cormorant Garamond`, `Cinzel`).
  - Progress bar at the bottom: `${n} OF 100 STATEMENTS APPEARED`.
- **Soundtrack Included**:
  - The exact background music from the video (`music.mp3`) with animated sound wave equalizer and mute/unmute control.
  - Auto-play on first touch/interaction.
- **Mobile First & Responsive**:
  - Full viewport height (`100dvh`), notch/safe-area friendly.
  - Touch swipe gestures: swipe left for Next, swipe right for Previous.
  - Double-tap anywhere on screen to send floating hearts and save to favorites!
- **Personalize For Anyone**:
  - Click the title to personalize the recipient's name (e.g. `100 THINGS ABOUT SOPHIA`).
  - Instant shareable link support: `?name=Sophia` or `?quote=44`.
- **"Browse 100" Celestial Drawer**:
  - Search any word across all 100 reasons.
  - Filter by your saved favorites.
  - Jump directly to any number (1 to 100).
- **Share & Save**:
  - One-click copy quote or share direct link to any statement.
  - Golden confetti celebration.

## 🚀 How to Run

### Development Server:
```bash
npm run dev
```

### Production Build:
```bash
npm run build
```

### Preview Built App:
```bash
npm run preview
```
Visit `http://localhost:4173` on desktop or `http://192.168.1.107:4173` on mobile devices connected to the same Wi-Fi.

## ⌨️ Keyboard Shortcuts
- **Right Arrow / Space / K**: Next statement
- **Left Arrow / J**: Previous statement
- **F**: Toggle Favorite
- **Space**: Play / Pause slideshow
